# ST015 检查是否存在属性限制

## 步骤描述

1.获取属性级限制：根据{账号}查询【对公存款账户限制表（RB_BUS_RESTRAINTS）】获取$限制状态$等于"A-生效"且$限制级别$等于"NATURE-账户属性限制"的[账户限制信息]，必须包括$账户限制类型$、$限制编号$

2.检查是否存在属性限制：若{账户限制信息}等于空，则返回[属性限制标志]为“否”，否则返回[属性限制标志]为“是”；{账户限制信息}存在多条时，取$限制编号$按数值比较最小的一条填充$限制编号$、$账户限制类型$、$限制状态$、$限制级别$。

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

|--------|------|------|----------|------|
| natureRestraintFlag | java.lang.String | 非必填 | | 属性限制标志 |

| resSeqNo | java.lang.String | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制编号 |

| restraintsStatus | com.dcits.validation.enums.RestraintsStatus | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制状态 |
| restraintLevel | com.dcits.validation.enums.RestraintLevel | 非必填 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 限制级别 |
