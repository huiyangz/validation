# ST005 检查账户是否存在限制

## 步骤描述

1.获取主账户账号：若上送的{账号}是子账户，则根据{账号}查询【账户信息】获取$上级账户内部键$，再根据$上级账户内部键$查询【账户信息】获取$主账户账号$，否则继续执行。

2.设置待查账户：若上送的{账号}是子账户，则赋值[待查账户]为[主账户账号]，否则赋值[待查账户]为{账号}。
3.获取账户限制：根据[待查账户]查询【对公存款账户限制表】（RB_BUS_RESTRAINTS）获取$限制状态$等于"A-生效"的[账户限制信息]，必须包括$账户限制类型$、$限制编号$

4.检查账户是否存在限制：赋值账户限制信息并返回[账户限制信息]。
