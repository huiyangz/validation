# ST008 检查是否存在现金止收限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，必须包括$账户限制类型$、$限制编号$
2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$现金标志$

3.检查是否存在现金止收限制：若[账户限制信息]中任一限制记录的限制类型对应的$借贷方控制标志$等于"C-禁止贷方"且$现金标志$等于"N-不允许现金"，则返回现金止收标志为“是”，否则返回现金止收标志为“否”。输出字段resSeqNo、restraintType、restraintsStatus取满足上述条件的首条限制记录，restraintTypeDef、status、drCrCtlFlag、cashFlag取该记录限制类型对应的【限制类型表】信息，无满足条件的记录时上述字段为空。
