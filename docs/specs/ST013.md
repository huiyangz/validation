# ST013 检查账户是否存在不允许销户的限制

## 步骤描述

1.检查销户标志：遍历{账户限制信息}（账户限制信息为输入提供的账户限制记录集合，元素包含限制编号、账户限制类型、限制状态、限制级别字段）
1）取当前遍历记录的$账户限制类型$查询【限制类型信息】获取$销户标志$
2）若$销户标志$为“N-否”，则返回[允许销户标志]为“不允许销户”并中断遍历，否则继续遍历
结束遍历，返回[允许销户标志]为“允许销户”

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| restraintList | java.util.List<账户限制信息DTO> | 必填、dto、集合 | 对公存款账户限制表（RB_BUS_RESTRAINTS） | 账户限制信息集合；元素（dto）字段：resSeqNo-限制编号、restraintType-账户限制类型（com.dcits.validation.enums.RestraintType）、restraintsStatus-限制状态（com.dcits.validation.enums.RestraintsStatus）、restraintLevel-限制级别（com.dcits.validation.enums.RestraintLevel） |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| allowCloseAcctFlag | java.lang.String | 非必填 | | 允许销户标志；取值：“允许销户”、“不允许销户” |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 限制类型 | 账户限制类型、输入数据-账户限制类型 |
| 限制状态 | 限制状态、输入数据-限制状态 |
| 限制级别 | 限制级别、输入数据-限制级别 |

## 提示

- {账户限制类型,输入数据-账户限制类型}取值来源于代码[限制类型]，对应枚举类-类名：com.dcits.validation.enums.RestraintType
- {限制状态,输入数据-限制状态}取值来源于代码[限制状态]，对应枚举类-类名：com.dcits.validation.enums.RestraintsStatus
- {限制级别,输入数据-限制级别}取值来源于代码[限制级别]，对应枚举类-类名：com.dcits.validation.enums.RestraintLevel

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
