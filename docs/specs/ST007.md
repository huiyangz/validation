# ST007 检查质押类限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，[账户限制信息]为该账号全部生效限制记录的集合，可为空；每条记录必须包括$账户限制类型$、$限制编号$
2.获取质押标志：按顺序遍历[账户限制信息]，对每条记录根据其$账户限制类型$查询【限制类型表】取$状态$等于"A-生效"的$质押标志$；取到首个非空$质押标志$后停止遍历，该记录的$限制编号$、$账户限制类型$、$限制状态$与[质押标志]一并作为输出返回；遍历结束仍无命中时输出字段均为空，步骤以成功状态返回

| baseAcctNo | java.lang.String | 必填 | | 账号 |
