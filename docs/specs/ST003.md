# ST003 检查有权机关冻结限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，[账户限制信息]为记录集合（同一账号可存在多条生效记录），必须包括$账户限制类型$、$限制编号$；无生效记录时[账户限制信息]为空集合，步骤成功返回，[有权机关冻结标志]为空

2.获取有权机关冻结标志：根据[账户限制信息]中各条记录的$账户限制类型$逐一查询【限制类型表】，只要查询到$状态$等于"A-生效"的$有权机关冻结标志$即赋值并返回[有权机关冻结标志]；均未查询到时[有权机关冻结标志]为空

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| baseAcctNo | java.lang.String | 必填 | | 账号 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| ahBuFlag | java.lang.String | 非必填 | | 有权机关冻结标志 |

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
