# ST011 检查限制优先级

## 步骤描述

1.获取交易的限制级别：根据{交易类型}查询【交易定义信息】获取交易的$限制级别$
2.获取限制的冻结级别：根据{账户限制类型}查询【限制类型定义信息】获取限制的$冻结级别$

3.检查限制优先级：若交易的[限制级别]数值大于账户限制类型对应的[冻结级别]，则返回检查结果“不检查限制”，否则返回检查结果为“继续检查”（按数值比较，需同时确认 RES_PRIORITY 取值为数字编码）

## 输入

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| tranType | com.dcits.validation.enums.OthTranType | 必填 | | 交易类型 |
| restraintType | com.dcits.validation.enums.RestraintType | 必填 | | 账户限制类型 |

## 输出

| 字段名 | 类型 | 标记 | 来源实体 | 说明 |
|--------|------|------|----------|------|
| checkResult | java.lang.String | 必填 | | 检查结果：“不检查限制”或“继续检查” |

## 相关枚举

| 枚举 | 别名 |
|------|------|
| 交易类型 | 交易类型、输入数据-交易类型 |
| 限制类型 | 账户限制类型、输入数据-账户限制类型 |

## 提示

- {交易类型,输入数据-交易类型}取值来源于代码[交易类型]，对应枚举类-类名：com.dcits.validation.enums.OthTranType
- {账户限制类型,输入数据-账户限制类型}取值来源于代码[限制类型]，对应枚举类-类名：com.dcits.validation.enums.RestraintType

## 失败处理

本步骤无业务失败场景，失败仅由技术异常传播表达。
