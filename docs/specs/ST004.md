# ST004 检查转账止收限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]（{账号}下全部生效限制的记录集合，可为空集），必须包括$账户限制类型$、$限制编号$

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$、$止付标志$

3.检查转账止收限制：对[账户限制信息]中各条记录对应的限制类型，若存在任一记录的$借贷方控制标志$等于"C-禁止贷方"且$转账标志$等于"N-不允许转账"，则返回转账止收标志为“是”，其余输出字段取命中记录及其限制类型对应信息，存在多条命中记录时取$限制编号$最小的一条；[账户限制信息]为空或均不满足时返回转账止收标志为“否”，其余输出字段置空。
