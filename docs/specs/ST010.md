# ST010 检查是否存在转账不收不付限制

## 步骤描述

1.获取账户限制信息：根据{账号}、$限制状态$等于"A-生效"查询【账户限制信息】获取[账户限制信息]，可能存在多条记录，逐条执行步骤2、步骤3的判断，任一命中即返回“是”及该条[账户限制信息]，必须包括$账户限制类型$、$限制编号$

2.获取账户限制类型信息：根据[账户限制信息]中的$账户限制类型$查询【限制类型表】获取$状态$等于"A-生效"的$借贷方控制标志$、$转账标志$
3.检查是否存在转账不收不付限制：若限制类型对应的$借贷方控制标志$等于"A-禁止借贷方"且$转账标志$等于"N-禁止转账"，则返回[账户限制信息]及转账不收不付标志为“是”，否则返回[账户限制信息]（如查询到）及转账不收不付标志为“否”。
